HIGH-LEVEL DATA FLOW & PIPELINE ARCHITECTURE:
----------------------------------------------------------------------------------------------------

 [ Gazebo Sim (lidarbot_gz) ]  OR  [ Real Wheelchair Hardware (lidarbot_bringup) ]
           │                                      │
           │ (/scan, /imu, /odom)                 │ (/scan, /imu, /odom)
           ▼                                      ▼
 [ AMCL Localization (lidarbot_navigation) ] ◄──► [ 2D Map Server (big_map_7.yaml) ]
           │
           │ (Robot Pose via /tf: map -> odom -> base_footprint)
           ▼
 [ osmAG Planner & Controller Node (lidarbot_osmag) ] ◄──► [ Semantic Map (big_map_7.osm) ]
           │
           │ 1. Receives /goal_pose from Foxglove Studio
           │ 2. Computes hierarchical A* topological route across room doorways (3 ms)
           │ 3. Publishes 3D area & doorway visual markers (/osmag/map_markers, /osmag/path_marker)
           │ 4. Drives robot wheels via Pure Pursuit controller (/cmd_vel)
           ▼
 [ Velocity Multiplexer (twist_mux) ]
           │
           │ Priority arbitration (/cmd_vel_joy > /cmd_vel)
           ▼
 [ Differential Drive Controller / Motor Driver (diff_controller) ] ──► WHEEL MOTION!

====================================================================================================
SUMMARY OF RUNTIME TOPICS & MESSAGES
====================================================================================================

| Topic Name                   | Message Type                     | Publishing Node           | Purpose                                      |
|------------------------------|----------------------------------|---------------------------|----------------------------------------------|
| `/scan`                      | `sensor_msgs/msg/LaserScan`      | Gazebo / rplidar_node     | 2D Laser rays for obstacles & AMCL           |
| `/odom`                      | `nav_msgs/msg/Odometry`          | ekf_node                  | Filtered wheel odometry + IMU position       |
| `/tf`                        | `tf2_msgs/msg/TFMessage`         | robot_state_publisher/amcl| Full spatial coordinate transform tree       |
| `/map`                       | `nav_msgs/msg/OccupancyGrid`     | map_server                | 2D static floorplan grid                     |
| `/goal_pose`                 | `geometry_msgs/msg/PoseStamped`  | Foxglove Studio / RViz2   | Target navigation destination clicked by user|
| `/osmag/map_markers`         | `visualization_msgs/MarkerArray` | osmag_planner_node        | 3D green room polygons & red doorway markers |
| `/osmag/global_path`         | `nav_msgs/msg/Path`              | osmag_planner_node        | Computed hierarchical multi-room path        |
| `/osmag/path_marker`         | `visualization_msgs/Marker`      | osmag_planner_node        | 3D thick magenta route line for Foxglove     |
| `/cmd_vel`                   | `geometry_msgs/msg/Twist`        | osmag_planner_node        | Wheel linear & angular velocity commands     |
| `/diff_controller/cmd_vel...`| `geometry_msgs/msg/Twist`        | twist_mux                 | Arbitrated motor command fed to wheels       |
